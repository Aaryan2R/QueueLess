# QueueLess – Scope

## In Scope
- Multi-business web platform.
- Owner authentication.
- Business profile/customization.
- Queue creation/configuration.
- QR-based public entry.
- Customer queue joining without a native app.
- Ticket and position tracking.
- Staff operations.
- Real-time updates.
- Basic analytics.
- Queue history.
- Security and role-based access.

## Out of Scope for Initial Submission
- Full payment gateway.
- Native mobile applications.
- Advanced AI prediction.
- Full enterprise appointment scheduling.
- POS integration.
- Table reservation engine.
- Medical records.

## Scope Control Rule
New features should be added only when the core queue lifecycle is stable and demonstrable.
