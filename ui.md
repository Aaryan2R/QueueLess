# QueueLess – UI Specification

## Public Marketing Site
Sections:
- Hero
- Problem
- How it works
- Features
- For businesses
- Pricing placeholder / plans
- Call to action

Primary CTA:
**Create Your Queue**

## Business Dashboard
### Overview Cards
- Active Queue
- Waiting Customers
- Average Wait
- Served Today

### Navigation
- Overview
- Queues
- QR Codes
- Staff
- Analytics
- Business Customization
- Settings

## Customer Page
The page should prominently show:

```text
BUSINESS LOGO
BUSINESS NAME
Queue Name

TICKET: A27

Your Status
WAITING

3 groups ahead
Estimated wait: 12 min

[Leave Queue]
```

## Staff Screen
The primary action should be easy to find:

**CALL NEXT**

Then show the current ticket and a compact list of waiting tickets.

## Responsive Behavior
- Desktop: sidebar + dashboard layout.
- Tablet: compact two-column layout.
- Mobile: stacked cards and large touch-friendly controls.

## Accessibility
- Every form control has a label.
- Focus states are visible.
- Status should not rely only on color.
- Buttons use descriptive text.
- Error messages are associated with the relevant field.
