# QueueLess – User Stories

## Business Owner
- As a business owner, I want to create my business profile so that I can use QueueLess for my business.
- As a business owner, I want to customize my queue page so that it matches my branding.
- As a business owner, I want to configure queue rules so that the system matches my operating process.
- As a business owner, I want to generate a QR code so that customers can join quickly.
- As a business owner, I want to add staff so that employees can operate the queue.
- As a business owner, I want to pause a queue so that I can stop accepting new customers during overloads.
- As a business owner, I want analytics so that I can understand waiting patterns.

## Staff
- As staff, I want to see the live waiting list so that I know who is next.
- As staff, I want to call the next customer so that the queue advances.
- As staff, I want to mark a ticket no-show/cancelled/served so that the list stays accurate.

## Customer
- As a customer, I want to join by scanning a QR code so that I do not need to search for the business online.
- As a customer, I want a ticket number so that I know my place in line.
- As a customer, I want to see an estimated wait so that I can decide whether to wait.
- As a customer, I want the status to update automatically so that I do not need to refresh repeatedly.
- As a customer, I want to leave the queue if my plans change.

## Platform Admin
- As a platform admin, I want to manage businesses so that the platform remains controlled and reliable.
